```tsx
import { Tile } from "@zupy/ui";

<Tile variant="success">Z</Tile>
```

## Pop in

Set `pop` to play a springy entrance. Change the `key` to replay it when the content changes.

```tsx
<Tile pop key={letter} variant="accent">
  {letter}
</Tile>
```

## Props

| Prop      | Type                                                                                              | Default     |
| --------- | ------------------------------------------------------------------------------------------------- | ----------- |
| `variant` | `"empty" \| "neutral" \| "primary" \| "accent" \| "success" \| "warning" \| "danger" \| "muted"`  | `"neutral"` |
| `size`    | `"sm" \| "md" \| "lg"`                                                                            | `"md"`      |
| `pop`     | `boolean`                                                                                         | `false`     |
| `render`  | `ReactElement`                                                                                    |             |
