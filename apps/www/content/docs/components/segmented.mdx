title: Segmented
description: Pick one of a few options. One is always selected.
---

<Preview>
  <Segmented defaultValue="week" aria-label="Range">
    <SegmentedItem value="day">Day</SegmentedItem>
    <SegmentedItem value="week">Week</SegmentedItem>

  </Segmented>
</Preview>

```tsx
import { Segmented, SegmentedItem } from "@zupy/ui";

<Segmented defaultValue="week" aria-label="Range">
  <SegmentedItem value="day">Day</SegmentedItem>
  <SegmentedItem value="week">Week</SegmentedItem>
  <SegmentedItem value="month">Month</SegmentedItem>
</Segmented>
```

The selected item is raised in the accent color. Clicking the selected item again does nothing, so there is always a selection.

## Props

### Segmented

| Prop            | Type                      | Default        |
| --------------- | ------------------------- | -------------- |
| `value`         | `string`                  |                |
| `defaultValue`  | `string`                  |                |
| `onValueChange` | `(value: string) => void` |                |
| `orientation`   | `"horizontal" \| "vertical"` | `"horizontal"` |
| `disabled`      | `boolean`                 | `false`        |

### SegmentedItem

| Prop       | Type      | Default  |
| ---------- | --------- | -------- |
| `value`    | `string`  | required |
| `disabled` | `boolean` | `false`  |
